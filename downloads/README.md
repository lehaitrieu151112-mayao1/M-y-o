# Tiện ích Windows cho VPS

Thư mục này chỉ chứa shortcut và danh sách đường dẫn chính thức, không chứa bộ cài hay tệp thực thi.

- `software-catalog.json`: danh sách các ứng dụng Windows thông dụng từ nguồn chính thức.
- `apps/*.url`: shortcut Internet Shortcut tới trang của nhà phát hành.

Các tệp cài đặt cần được tải từ trang chính thức bên trong Windows VM sau khi bạn kết nối. Không commit bộ cài, mật khẩu, hay dữ liệu cá nhân vào repo công khai.
