# Changelog

## 2026-10-22
- Split the public game library and PC workspace into separate pages.
- Added a curated catalogue of PC games with HTTPS links to publisher/store pages.
- Added reusable PC storage, app-rendering, browser-launcher and file-explorer modules.
- Added an 18-item official Windows software catalogue and a local download manager.
- Added GitHub JSON catalogue snapshots and 30 official `.url` source shortcuts (18 software + 12 games).
- Added explicit import/copy of user-selected installer files into a directory the user has granted to File Explorer, plus local manifest export.
- Added local PC profiles, configurable target specs, window controls, Start menu and taskbar.
- Added Google-style search launcher, official-site bookmarks and browser/fullscreen controls.
- Added explicitly permissioned File System Access API integration where supported.
- Added PWA manifest, app icon, service worker and smoke checks.
- Documented that the current free demo does not provision a real VPS or GPU.
