🚀 Lộ trình phát triển

  • Thư viện game PC, tìm kiếm, bộ lọc và game yêu thích.
  • Trang chi tiết: cấu hình tối thiểu/đề xuất, dung lượng và nguồn tải chính thức.
  • Đăng nhập và đồng bộ danh sách yêu thích bằng Supabase.
  • Ứng dụng Windows tải về để mở game đã cài và quản lý đường dẫn.
  • Tích hợp trình giả lập hoặc dịch vụ cloud gaming tương thích.

Chỉ nên tải game từ cửa hàng hoặc nhà phát hành đáng tin cậy. Chạy và tự cài game trực tiếp cần ứng dụng Windows riêng; tính năng máy chủ đám mây sẽ được xem xét ở giai đoạn sau.

Lưu ý: đây là bản demo giao diện. Danh sách gồm game PC mẫu, không phải kho tải game đầy đủ. Một số game yêu cầu mua bản quyền, tài khoản, phần cứng phù hợp hoặc launcher riêng.
