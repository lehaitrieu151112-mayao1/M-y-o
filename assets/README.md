# Front-end assets

- `app-icon.svg`: icon của cổng M-Y-O VPS.
- `pwa.js`: đăng ký service worker để lưu cache tĩnh.
- `pc-drive-ui.js` và `pc-virtual-disk.js`: các module tiện ích lưu trữ/hiển thị đĩa ảo được giữ lại cho phát triển tiếp theo.

Trang chủ `index.html` và trang kết nối `pc.html` hiện dùng CSS/JavaScript nội tuyến, không cần bộ build frontend riêng.
