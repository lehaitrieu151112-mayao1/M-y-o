🛠️ Dựng máy chủ thật

Code triển khai nằm trong repository. Chạy trên Linux VPS hoặc máy Linux có Docker Compose v2.

  1. Tải repository M-Y-O về máy chủ Linux.
  2. Từ thư mục gốc, chạy chmod +x scripts/bootstrap-cloud-pc.sh.
  3. Chạy ./scripts/bootstrap-cloud-pc.sh. Script sinh mật khẩu ngẫu nhiên nếu chưa có .env, sau đó build và chạy desktop + API ổ đĩa.
  4. Cấu hình domain và HTTPS bằng Caddy. Xem hướng dẫn Cloud PC.
  5. Mở domain HTTPS rồi đăng nhập bằng thông tin máy chủ đã tạo. File tải sẽ nằm trong phiên Linux từ xa.
Code đã có ≠ máy chủ đang chạy

Repo này không tự thuê host hoặc khởi động container trên Internet. Trước khi deploy lên host thật, trang kết nối sẽ không có địa chỉ để dùng.
