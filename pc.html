🛠️ Khởi chạy Windows VM thật

Cần Linux VPS x86_64 có KVM, đủ RAM/SSD, domain và Docker Compose v2.

  1. Thuê Linux VPS cloud x86_64 hỗ trợ KVM/TUN; trỏ DNS domain (ví dụ pc.example.com) về IP công khai và mở cổng 80/443.
  2. Mở SSH hoặc web console của VPS. Đây là terminal trên máy chủ cloud, không phải terminal trên máy cá nhân.
  3. Chạy curl -fsSLO https://raw.githubusercontent.com/lehaitrieu151112-mayao1/M-y-o/main/install-vps.sh && sudo bash install-vps.sh pc.example.com.
  4. Đợi trình cài hoàn tất và Windows khởi động lần đầu; xem trạng thái bằng cd /opt/myo-windows-vps && docker compose logs -f windows-vm.
  5. Đăng nhập cổng bảo vệ rồi đăng nhập Windows bằng thông tin in ra ở terminal. Tệp tải sẽ lưu trên đĩa VM.
